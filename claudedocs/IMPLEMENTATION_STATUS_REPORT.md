## 🔍 크로스 DB 연동 현재 분석

### 현재 고유성 메커니즘
```typescript
// Table.ts에서 identifier 기반 고유성
static create(identifier: string, description?: string): Table {
  if (!/^[a-zA-Z][a-zA-Z0-9_-]*$/.test(identifier)) {
    throw new DomainException('Table identifier must start with a letter...')
  }
}

// Node.ts에서 tableId 연결
constructor(
  private readonly id: NodeId,
  private readonly tableId: TableId,  // 테이블과의 연결
  // ...
)
```

### 크로스 DB 연동을 위한 기존 인프라 활용도
- **✅ 강점**: `Table.identifier`를 통한 논리적 고유성 기반 구축 가능
- **✅ 확장성**: 현재 구조에 `databaseInstanceId` 개념 추가 가능
- **⚠️ 제약사항**: SQLite 단일 파일 기반 아키텍처
